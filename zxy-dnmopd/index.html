结论速览 TL;DR

一句话：多教师在线蒸馏(MOPD)只做了一半——它用领域标签决定每个 prompt 由哪个教师监督，却默认所有教师的反馈强度相等。本文发现这个默认是错的：不同领域的"教师−学生 log 比值"尺度天差地别，指令遵循(IF)的反馈离散度是整体的 2.3–4.4 倍，在 4B 学生首个 batch 里 IF 独占了 94% 的梯度。DN-MOPD 只加一步按领域方差归一化的缩放 wd = clip(σall/σd, 0.25, 4)，不加教师、不加路由器、不改 loss，就在 9B/4B/2B 三个尺寸上全部超过标签路由。

核心增益：六任务 Total 在 16K 评测上 +1.17～+2.36，8K 上 +2.47～+3.08，每个配对 95% 区间都在零以上。增益主要来自调低 IF 的反馈而非换教师。诚实之处：作者明说 DN-MOPD 不是整体最强配方（SeqKD-SFT、参数合并 Total 更高）。

1 · 概览

研究问题在多教师在线蒸馏(MOPD)里，仅靠"按领域标签把 prompt 分给对应教师"是否足够？不同领域教师的监督信号尺度是否可比、要不要重新加权？ 核心发现不够。各领域的"教师−rollout log 比值"离散度差异巨大，离散度大的领域(IF)会在聚合梯度里占据压倒性比重，淹没其他领域——标签路由因此在三个尺寸上都没能超过最强单教师学生。 核心方法DN-MOPD：保留标签路由，每个 batch 额外算一个有界、保号的按领域缩放系数 wd=clip(σall/σd,0.25,4)，把优势 At 缩放成 Ãt=wd·At。无需额外教师调用、独立路由器或学习参数；令全部 wd=1 即退化为标签路由。 主要结论DN-MOPD 在 9B/4B/2B 全部超过标签路由，数学增益最大；消融证明增益主要来自调低 IF 反馈。但作者明确界定边界：它不是整体最强的能力融合配方。 适用边界Qwen3.5 单一模型族、non-thinking、2B/4B/9B；教师池固定为数学/代码/IF 三个同尺寸 GRPO 专家。更大规模、thinking 模式、跨模型族未验证。

2 · 方法剖析

基础框架：标签路由的 MOPD

MOPD 把领域 d 的 prompt 路由到该领域专家 Td，学生 πu 自采样回答 y，在位置 t、上下文 ht 处用token 级优势训练：

At = log pTd(yt|ht) − log πu(yt|ht)

At 直接占优势位（无需 critic），学生用 PPO 式 clipped OPD 目标最大化。标签路由隐含了一个默认假设：所有领域教师的 At 可以直接相加、强度相等。

关键诊断：反馈尺度在领域间天差地别

作者先做了一个被所有 MOPD 工作忽略的测量：把"教师 log 概率 − rollout log 概率"的离散度 σ 按领域分别统计。结果IF 的 log 比值离散度是整体的 2.3–4.4 倍，数学只有约一半。因为聚合时各领域优势直接相加，离散度大的 IF 就主导了梯度——

例 · IF 如何"吞掉"梯度
对 4B 初始学生，IF token 仅占全部回答 token 的约 1%，却贡献了池化 log 比值方差的近一半。在等权聚合下，IF 损失供给了 94% 的合并梯度——数学和代码的监督信号被淹没。这解释了为何标签路由"换了教师却学不到各专家的本事"。

核心方法：按领域方差归一化（DN）

DN-MOPD 保留标签路由，每个 batch 只加一步保号的缩放：

wd = clip( σall / σd , 0.25 , 4 )，Ãt = stopgrad(wd) · At

σd 是该领域 batch 内响应 token 上"教师−rollout log 比值"的标准差，σall 是跨所有领域池化的同一统计量。乘子恒为正 → 每个优势保持符号；clip 到 [0.25,4] 防止极端缩放。令全部 wd=1 即退化为标签路由。无需额外教师调用、独立路由器或可学习参数。

例 · 首个 batch 的真实缩放系数（4B DN-MOPD, seed 42）
实测离散度：σmath=0.306、σcode=0.756、σIF=1.798、σall=0.614。代入 wd=σall/σd：
· 数学 0.614/0.306 ≈ ×2.01（离散度最小 → 放大）
· 代码 0.614/0.756 ≈ ×0.81
· IF 0.614/1.798 ≈ ×0.34（离散度最大 → 压低）
效果：合并梯度里 IF 的占比从 94% 降到 64%，把被淹没的数学/代码信号放回来——这正是增益的来源。

消融：增益到底来自哪？

  • 换教师分配没用：改成 uniform pool 或 dynamic router，相对标签路由无一致增益——问题不在"谁教"，在"反馈强度"。
  • 只压低 IF 就复现大半增益：在 4B/2B 的定权控制里，仅把 IF 权重降到 0.25 就能恢复 DN-MOPD 的大部分提升；仅把数学加倍只恢复约一半(4B)、更少(2B)。
  • 首个 batch 的权重几乎够用：把权重固定成 DN-MOPD 首 batch 乘子，在 9B/4B 与逐 batch 估计无可检测差异；仅 2B 逐 batch 估计好 1.10 分。
  • 专长可解释：乘子随训练动态变化（IF 常被 clip 到下限 0.25），放大小离散度领域、压低大离散度领域，与"IF 吞噬梯度"的诊断一致。

4 · 相关工作与定位

本文处在 On-Policy Distillation → Multi-Teacher OPD (MOPD) 这条线上，与能力融合的其它路线（离线蒸馏 SeqKD-SFT、参数合并 model merging、联合/顺序 RL）并列比较，并坦承后两者在各自配方下 Total 更高。

与姊妹工作 MOPD-Router 的关系（强烈推荐对照阅读）：两篇都针对"标签路由"的局限，但切入点正交——

  • MOPD-Router (zxy-pprds) 攻击"谁来教"：去掉领域标签，改成 token 级软路由（ExpertAlign 指标逐 token 给每个教师打分加权）。
  • DN-MOPD (本文) 攻击"教多重"：保留标签路由，只在领域粒度上按方差归一化反馈强度。

一个重分配"路由权重"，一个重标定"反馈尺度"。两者可正交组合——DN-MOPD 的诊断（领域反馈尺度不可比）其实也解释了为何单纯换路由策略收益有限。

6 · 批判性分析：水分程度与价值判断

实打实的贡献

  • 诊断真实且反直觉：首次量化"领域反馈尺度不可比"并指出 IF 占 1% token 却吃掉 94% 梯度——这是一个被整条 MOPD 线忽略的真问题，不是造出来的靶子。
  • 方法极简且保号：一行 clip(σall/σd,0.25,4)，不加教师/路由器/参数、不改 loss，令 w=1 即退化基线——干净、可解释、好接入。
  • 验证严谨：3 尺寸 × 2 长度、配对 95% bootstrap 全部 >0、3 seed 复测；消融用定权控制把增益精确归因到"调低 IF"。
  • 罕见的诚实：主动声明不是整体最优配方（SeqKD/合并 Total 更高）、相对最强单教师学生的增益更小且部分区间含 0——与常见的 overclaim 完全相反。
  • 开源到位：21 权重 + 逐题记录 + CPU 可执行自校验 ALL MATCH。

水分 / 需谨慎看待处

  • 绝对增益中等：Total 多在 +1～+3 分；"最优"是多教师 OPD 组内最优，而非跨所有融合路线最优。
  • 规模与模型族单一：仅 Qwen3.5 的 2B/4B/9B、non-thinking；更大规模、thinking、跨模型族未验证。
  • 教师池固定三领域同尺寸：异构尺寸、教师质量参差、更多领域时的鲁棒性未测。
  • 归一化本质是启发式：σ 比值 + clip 边界(0.25/4)为经验设定；为何方差是正确的归一化量、而非别的尺度统计，缺乏理论刻画。
